# 보디가드

혼자 계신 부모님 곁을 지키는 안심 앱. 큰 버튼 하나만 누르면 가족에게 **문자와 현재 위치**가 전송됩니다.

작은앱공방에서 만들었습니다.

## 왜 문자인가

카카오톡이 아니라 **문자(SMS)** 를 씁니다. 문자는 통신사 망으로 전송되어
**데이터가 끊긴 곳에서도 발송**되기 때문입니다. 위급 상황에 인터넷 연결을 전제할 수 없습니다.

## 기능

- **도움 요청(응급)** — 가족에게 즉시 문자 발송 후, 위치가 확보되는 대로 이어서 전송
- **상황별 버튼** — 택시 불러주세요 / 길을 잃었어요 / 도착했어요 / 전화 걸기
- **무동작 감시** — 12시간 동안 휴대폰을 쓰지 않으면 자동으로 안부 문자
- **배터리 알림** — 배터리가 부족하면 가족에게 알림
- **오작동 취소** — 잘못 눌렀을 때 취소 문자를 보낼 수 있음
- **연락처 2순위** — 1·2순위에 각각 발송하며, 하나라도 성공하면 성공 처리

## 개인정보

연락처와 위치는 **기기에만 저장**됩니다. 외부 서버로 수집·전송하지 않으며,
위급 시 사용자가 직접 지정한 가족에게 **문자로만** 전달됩니다.

## 기술 구성

- React + Vite
- Capacitor (Android 네이티브 래핑)
- 커스텀 `SmsPlugin` — 문자 발송, 배터리 최적화 확인
- `@capacitor/geolocation` — 위치

## 개발

```bash
npm install
npm run dev          # 웹 개발 서버 (문자·위치는 동작하지 않음)
npm run build
npx cap sync android
npx cap open android # Android Studio에서 빌드
```

> 문자 발송·백그라운드 감시는 **네이티브 기능**이라 웹 브라우저에서는 확인할 수 없습니다.
> 반드시 실기기에서 테스트하세요.

## 배포 메모

- 서명키(`*.keystore`, `*.jks`)와 `keystore.properties`는 **저장소에 올리지 않습니다.**
- 빌드된 APK는 저장소가 아니라 **GitHub Releases**로 배포합니다.
